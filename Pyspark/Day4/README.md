# Day 4 - PySpark Learnings

## Topics Learned

- `limit()` – Used to limit the number of rows in a DataFrame.
- `drop()` – Used to remove columns from a DataFrame.
- `dropDuplicates()` – Used to remove duplicate rows.
- Creation of DataFrames in PySpark.
- `union()` – Used to combine two DataFrames with the same schema.
- `unionByName()` – Used to combine DataFrames based on column names.

## String Functions

- `upper()` – Converts text to uppercase.
- `lower()` – Converts text to lowercase.
- `initcap()` – Converts the first letter of each word to uppercase.
