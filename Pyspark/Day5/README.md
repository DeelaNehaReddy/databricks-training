# Day 5 - PySpark Learnings

## Topics Learned

- `current_date()` – Used to get the current system date.
- `date_add()` – Used to add days to a date column.
- `date_sub()` – Used to subtract days from a date column.
- `datediff()` – Used to find the difference between two dates.
- `date_format()` – Used to format date columns into different patterns.
