# Day 3 - PySpark Learning

## Topics Learned

- Applied `filter()` to filter rows based on conditions
- Used multiple conditions inside `filter()` for advanced filtering
- Learned `withColumnRenamed()` to rename existing columns
- Used `withColumn()` with `lit()` to create new constant value columns
- Learned `regexp_replace()` to replace text patterns in columns using regular expressions
- Used `orderBy()` to sort DataFrame data in ascending and descending order

## Outcome

Gained hands-on experience in performing data transformation, filtering, column modification, text replacement, and sorting operations using PySpark DataFrames.
