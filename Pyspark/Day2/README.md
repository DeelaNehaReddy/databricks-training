# Day 2 - PySpark Learnings

## Learnings

- Learned how to define and apply schema while reading data in PySpark
- Understood how to select only required columns from a DataFrame
- Learned column operations like using `col()` and renaming columns with alias
- Practiced different ways to display data using PySpark
- Learned how to sort data in ascending and descending order
- Learned how to display only limited number of rows using show and limit

## Outcome
Improved understanding of basic DataFrame operations in PySpark like schema, select, display, sorting, and filtering.
