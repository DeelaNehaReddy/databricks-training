
#  Day 3 – SQL Order By & Join Queries

##  Overview

Today’s SQL practice focused on **ORDER BY** and **JOIN** operations.
These concepts are essential for sorting data and combining information from multiple tables.

##  Topics Covered

###  ORDER BY Clause

Used to sort query results in:

* Ascending order (`ASC`)
* Descending order (`DESC`)

###  JOIN Operations

Used to combine records from multiple tables:

* `INNER JOIN`
* `LEFT JOIN`
* Filtering unmatched records
* Combining employee, department, and project data

---

## Queries Implemented

###  Order By Queries

* Employees ordered by salary (ascending)
* Employees ordered by age (descending)
* Employees ordered by hire date
* Employees ordered by department and salary
* Departments ordered by total salary expense

---

###  Join Queries

* Employee names with department names
* Project names with department names
* Employee names with project names
* Employees with or without departments
* Departments with or without employees
* Employees not assigned to any project
* Employees with project count by department
* Departments with no employees
* Employees sharing the same department as 'John Doe'
* Department with the highest average salary
